# MySQL Assignment 1

## Project Description
📌 Project Description
This project focuses on understanding and implementing MySQL Data Definition Language (DDL) commands and SQL Constraints for effective database management.
The main objective of this project is to create, modify, and manage database tables while maintaining data accuracy, consistency, and integrity.
🎯 Project Objectives

Create and manage databases using MySQL.
Implement DDL commands such as CREATE, ALTER, DROP, and TRUNCATE.
Apply SQL constraints such as PRIMARY KEY, FOREIGN KEY, UNIQUE, NOT NULL, DEFAULT, and CHECK.
Understand database structure and table relationships.
Practice SQL queries using MySQL Workbench.

🛠️ Tools & Technologies

Database: MySQL
Tool: MySQL Workbench
Language: SQL
Version Control: GitHub

✅ Conclusion
This project provides practical knowledge of MySQL database management, DDL operations, and SQL constraints. It helps build a strong foundation in database design and SQL development.
